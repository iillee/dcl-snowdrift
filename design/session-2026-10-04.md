## Scene scale

- **Shipped playtest envelope:** **64 × 64 parcels** (1024 m × 1024 m). Playfield **992 m** with the same **16 m** pad as the old 512 / 480 layout.
- Spawn hearth stays at playfield centre (tile ~31,31 → world ~512,512). Dawn pad and composite props were shifted to match.
- **v1 target envelope** remains **100 × 100** (~1600 m), gated on H1-06. **64 × 64 was the documented fallback** and is now the live playtest size — not a retreat from the 500 m inner-ring plan.
- **Deploy note:** Creator Hub Publish rewrites parcels from its Layout / SceneMetadata. CLI deploy (`npm run deploy -- --target-content https://worlds-content-server.decentraland.org`) uses `scene.json` and is how the 64 × 64 World went live. Keep Layout at 64 × 64 in Creator Hub, or Prefer CLI for parcel-sensitive publishes.

## Snow rendering

- Per-tile quadtree (16 → 8 → 4 → 2 → 1 m) is unchanged near the player and near melt lips.
- **Far from melt**, pristine roots coalesce into larger multi-tile **boxes** (32 / 64 / 128 m), largest first, with edge-based player keep and melt pads so large sheets cannot sit under the camera.
- Melt lips cap at **4 m** nodes so the hearth is not a 16 m snow cliff.
- Paper-thin far planes were retired for coarse sheets — single-sided planes read as purple sheets from the melt pit.

## Freeze ice (cross-platform)

- Remote ice still uses AvatarAttach on `AAPT_POSITION` with the existing desktop remote Y offset.
- Presence heartbeats carry a **mobile** flag. Desktop viewers add a small extra lift (**~0.22 m**) only when drawing ice on a mobile peer. Desktop–desktop and mobile viewers keep the previous offset.

## Overhead spectator

- Off-screen avatar finder: circular face bubble (Explorer-style portrait chrome) on the screen edge when free-pan leaves the local avatar off screen.
- Edge inset raised to **15%** so the bubble clears the HUD.

## Other polish in this merge

- Torch tip cube stays visible on relight (scale-hide instead of VisibilityComponent stickiness).
- Chop reach scales with tree size (from the prior main tip before this branch).
