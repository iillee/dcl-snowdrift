## Mobile leave-scene (blocking for phone playtests)

**Symptom.** On mobile, walking a few seconds from the spawn hearth (especially toward +X / +Z) drops the player out of the scene: content vanishes, scene UI dies, avatar falls. Desktop at the same World stays fine.

**Measured with `getSceneInformation` (same deploy):**

| Client | Live footprint | Edge from hearth (~800,800) |
|---|---|---|
| Desktop Explorer | **100 × 100 (10 000)** | ~800 m every way |
| Mobile Explorer | **51 × 51 (2 601) MISMATCH** | ~10–18 m north/east |

51 × 51 from base `0,0` is exactly the square that still contains parcel `50,50` (the hearth). The engine then treats ~816 m as the scene edge — so the hearth sits in the NE corner of the *mobile* footprint.

**Not the cause:** truncated World deploy (content server has the full list), terrain holes, or authored settings alone.

**Status:** Reported to Decentraland (mobile Explorer / large Worlds parcel metadata). Awaiting reply. Tracked as **H1-07**.

## Fuel tier sync (stuck flame / snow)

- Playtest desync: hearth flame size and melt ring stuck while other clients updated; snow/timer felt wrong.
- **Root cause:** `hearthFuelUpdate` used `Schemas.Float`. Values from `room.send` were not always Numbers, so the handler failed silently on some clients.
- **Fix:** coerce with `Number(...)` on the wire path so every client applies the same fuel tier.
